# Frontend

Это **Frontend вашей игры**. Здесь находится интерфейс игры, React-компоненты, Phaser-сцена и логика взаимодействия с вашим Backend.

## Установка

### 1. Установите зависимости

Откройте консоль в папке проекта и выполните:

```bash
npm install
```

### 2. Создайте `.env`

Переименуйте файл:

```text
.env.example
```

в:

```text
.env
```

Откройте `.env` и установите необходимые значения:

```env
VITE_API_URL=Ваш адрес Backend
VITE_CONNECT_URL=Ваш адрес TON Connect Manifest
VITE_BLOCK_ID=ID для Telegram Adsgram
VITE_PUBLIC_KEY=Ваш Public Key
VITE_BOT_USERNAME=Username вашего Telegram-бота
VITE_BOT_TOKEN=Ваш Bot Token

VITE_NETWORK=testnet
VITE_PROJECT_ID=Ваш Project ID
```

### Конфигурация

* `VITE_API_URL` — адрес **вашего Backend**, например `https://api.dev.qr-mint.net`.
* `VITE_CONNECT_URL` — адрес TON Connect Manifest, который используется для подключения TON-кошелька.
* `VITE_BLOCK_ID` — идентификатор рекламного блока Adsgram.
* `VITE_PUBLIC_KEY` — ваш публичный ключ.
* `VITE_BOT_USERNAME` — username вашего Telegram-бота.
* `VITE_BOT_TOKEN` — токен Telegram-бота. только для локальной версий
* `VITE_NETWORK` — сеть, например `testnet`.
* `VITE_PROJECT_ID` — Project ID, который необходимо получить в используемом сервисе.

> **Важно:** секретные ключи и токены нельзя публиковать в GitHub или передавать другим людям.

## Структура проекта

### `nginx/`

Конфигурация Nginx, используемая при деплое Frontend.

### `public/`

Публичные файлы проекта: изображения, иконки и другие статические ресурсы.

### `scripts/`

Вспомогательные скрипты проекта.

### `src/`

Основной исходный код Frontend.

#### `api/`

Набор методов и функций для взаимодействия с Backend.

Например:

```text
Frontend → API → Backend
```

Здесь находятся функции для отправки запросов и получения данных от вашего Backend.

#### `audio/`

Функции, связанные с музыкой и звуками игры.

#### `components/`

React-компоненты интерфейса.

Например:

* кнопки;
* окна;
* меню;
* панели;
* элементы интерфейса.

#### `game/`

Основная игровая логика.

Здесь находится Phaser и игровые сцены:

* игрок;
* враги;
* препятствия;
* уровни;
* столкновения;
* управление;
* игровая механика.

#### `helpers/`

Вспомогательные методы, которые используются в разных частях проекта.

#### `hooks/`

Кастомные React Hooks.

Они позволяют выносить повторяющуюся логику из React-компонентов.

#### `pages/`

Страницы приложения.

Например:

* главная страница;
* профиль;
* игра;
* достижения;
* лидерборд.

#### `providers/`

React Providers для глобальных сервисов и контекстов приложения.

#### `store/`

Глобальное хранилище состояния приложения.

Здесь могут храниться данные игрока, настройки, состояние игры и другие глобальные данные.

#### `utils/`

Дополнительные вспомогательные функции, которые используются в проекте.

# Game

Код игры на **Phaser.js** находится в:

```text
/src/game
```

Здесь находится основная логика игры и игровые объекты.

## `/src/game/scene`

В этой папке находятся основные сцены игры:

* `Background.ts` — отвечает за фон игры.
* `Game.ts` — основная сцена игры. Здесь находится основная игровая логика и взаимодействие игровых объектов.
* `Loader.ts` — отвечает за загрузку необходимых данных и ресурсов игры.
* `UIScene.ts` — интерфейс внутри игры. Здесь также находится логика управления персонажем.

## `/src/game/store`

Здесь находятся файлы, отвечающие за глобальное состояние **игровой логики**.

Это хранилище используется именно для данных, связанных с Phaser и игрой.

## `/src/game/subjects`

Здесь находятся игровые объекты, которые используются в игре.

Например:

* Player
* Enemy
* Obstacles
* другие игровые объекты

Эти объекты используются в основной сцене `Game.ts`.

## `/src/game/EventBus.ts`

Здесь находится `EventBus`.

Он используется для передачи событий и данных между разными частями игры и приложения.

Например, через `EventBus` можно передавать данные между Phaser и React.

## `/src/game/main.ts`

Здесь находится основная конфигурация **Phaser.js**.

Также здесь регистрируются сцены игры.

Если в игре понадобится добавить новую Phaser-сцену, её необходимо подключить здесь.

---

## `/pages/games`

Это React-код, который подключает игру на Phaser из:

```text
/src/game
```

Здесь также можно размещать React-компоненты, связанные с игрой.

Например, если какой-то элемент интерфейса сложно реализовать внутри `UIScene.ts`, его можно сделать обычным React-компонентом.

Для обмена данными между React и Phaser можно использовать:

* `EventBus`
* глобальное хранилище Zustand из `/src/store`

> Обратите внимание: `/src/game/store` и `/src/store` — это разные хранилища.

`/src/game/store` используется для состояния игровой логики.

`/src/store` используется для глобального состояния всего React-приложения.

---

## `/routes`

Здесь игра подключается к роутеру приложения.

Игра доступна по адресу:

```text
/game
```

---

### Главное

На этом этапе нам важно понять **где находится сама игровая логика**.

Основная игровая часть находится в:

```text
/src/game
```

React используется как оболочка приложения и для интерфейсов, которые могут быть удобнее реализованы вне Phaser.

Позже мы отдельно разберём уже **весь frontend и его архитектуру целиком**.
